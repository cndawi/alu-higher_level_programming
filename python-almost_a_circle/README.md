# Python - Almost a circle

This project covers Python OOP, inheritance, getters/setters, `*args`/`**kwargs`, JSON/CSV serialization, and unit testing with `unittest`.

## Files
* `models/base.py`: `Base` class for `id` management and JSON/CSV serialization.
* `models/rectangle.py`: `Rectangle` subclass of `Base`.
* `models/square.py`: `Square` subclass of `Rectangle`.
* `tests/test_models/`: Comprehensive `unittest` suite for `Base`, `Rectangle`, and `Square`.
