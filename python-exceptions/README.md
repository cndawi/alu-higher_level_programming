python-exceptions

This project covers handling and raising exceptions in Python 3, using try/except/finally.

Tasks

0. Safe list printing
File: 0-safe_print_list.py
Prints x elements of a list and returns the number of elements printed.

1. Safe printing of an integers list
File: 1-safe_print_integer.py
Prints an integer with "{:d}".format(). Returns True if printed, otherwise False.

2. Print and count integers
File: 2-safe_print_list_integers.py
Prints the first x elements of a list, only integers, and returns the count.

3. Integers division with debug
File: 3-safe_print_division.py
Divides two integers and prints the result in a finally block.

4. Divide a list
File: 4-list_division.py
Divides two lists element by element, handling type, zero division, and index errors.

5. Raise exception
File: 5-raise_exception.py
Raises a TypeError.

6. Raise a message
File: 6-raise_exception_msg.py
Raises a NameError with a given message.

Requirements
- Python 3 on Ubuntu
- Files start with #!/usr/bin/python3
- Files end with a new line
- Files are executable
- No module imports
