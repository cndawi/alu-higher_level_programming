# Python - Import & Modules

This project covers how to import functions from other Python files and
how to organize code into modules.

## Concepts covered

- Importing a function with `from module import function`
- Importing a whole module with `import module`
- Using the `if __name__ == "__main__":` guard so code does not run on import
- Printing formatted output with `str.format()`

## Requirements

- Python 3
- Files start with `#!/usr/bin/python3`
- Files are executable (`chmod u+x filename.py`)
- Code follows the PEP8 style (checked with `pycodestyle`)

## Files

| File | Description |
|------|-------------|
| `add_0.py` | Module that defines the `add(a, b)` function |
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
