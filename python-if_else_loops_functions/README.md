# Python - if/else, loops, functions

This project covers the basics of Python control flow and functions.

## Concepts covered

- `if`, `elif`, and `else` statements
- `while` and `for` loops
- The `%` (modulo) and `//` (integer division) operators
- Printing formatted output with f-strings

## Requirements

- Python 3
- Files start with `#!/usr/bin/python3`
- Files are executable (`chmod u+x filename.py`)

## Files

| File | Description |
|------|-------------|
| `0-positive_or_negative.py` | Prints whether a random number is positive, zero, or negative |
| `1-last_digit.py` | Prints the last digit of a random number and compares it to 5 |
