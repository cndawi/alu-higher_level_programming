# Python - Everything is object

This project explores how Python handles objects, references, mutability, and memory addresses under the hood—including `id()`, `type()`, `is` vs `==`, aliasing, shallow vs. deep copies, and how mutable and immutable types behave when passed to functions.

## Files

| File | Description |
| :--- | :--- |
| `0-answer.txt` | Function used to print the type of an object (`type`). |
| `1-answer.txt` | Function used to get a variable's memory address identifier (`id`). |
| `2-answer.txt` | Checks whether two variables with different integer values point to the same object. |
| `3-answer.txt` – `18-answer.txt` | Short-answer checks on object identity, equality, aliasing, and mutability. |
| `19-copy_list.py` | Function `copy_list(l)` that returns a shallow copy of a list. |
| `20-answer.txt` – `28-answer.txt` | Short-answer checks on tuples, single-element tuples, and CPython object pre-allocation. |
