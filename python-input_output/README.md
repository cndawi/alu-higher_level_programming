# Python - Input/Output

This project covers file handling and JSON serialization/deserialization in Python, including reading, writing, and appending to UTF-8 text files using the `with` statement, as well as converting Python data structures to and from JSON strings and files.

## Files

| File | Description |
| :--- | :--- |
| `0-read_file.py` | Reads a UTF-8 text file and prints its contents to `stdout`. |
| `1-write_file.py` | Writes a string to a UTF-8 text file and returns the number of characters written. |
| `2-append_write.py` | Appends a string at the end of a UTF-8 text file and returns the number of characters added. |
| `3-to_json_string.py` | Returns the JSON representation of an object (string). |
| `4-from_json_string.py` | Returns a Python object represented by a JSON string. |
| `5-save_to_json_file.py` | Writes an object to a text file using a JSON representation. |
| `6-load_from_json_file.py` | Creates an object from a JSON file. |
| `7-add_item.py` | Script that adds all command-line arguments to a Python list and saves them to a JSON file. |
| `8-class_to_json.py` | Returns the dictionary description with simple data structures for JSON serialization of an object. |
| `9-student.py` | Defines a `Student` class with a `to_json` method. |
| `10-student.py` | Extends `Student` to filter attributes in `to_json`. |
| `11-student.py` | Extends `Student` with a `reload_from_json` method. |
| `12-pascal_triangle.py` | Returns a list of lists of integers representing Pascal’s triangle of size `n`. |
