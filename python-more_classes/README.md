# 0x08. Python - More Classes and Objects

This directory is part of the `alu-higher_level_programming` repository. It continues with object-oriented programming in Python by building a `Rectangle` class step by step.

## Learning Objectives

- What a class is and how to define one
- What an instance is and how to create one
- What `__init__` does
- How to use properties (`@property`) with getters and setters
- What a private attribute is and how name mangling works (`__width` becomes `_Rectangle__width`)
- How to validate the type and value of an attribute in a setter
- How to define `__str__` to control what `print()` and `str()` show
- How to raise `TypeError` and `ValueError` with custom messages
